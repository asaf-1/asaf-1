# About Me

I build automation infrastructure that turns complex product ecosystems into reliable, actionable release signals.

With 6 years of experience across SaaS, Multi-Tenant, E-Commerce, and WMS platforms, I specialize in taking automation from an empty repository to a production-ready engineering platform. My work covers test architecture, Playwright and TypeScript, isolated Docker execution, test-data management, parallelization, CI/CD integration and quality gates, failure diagnostics, and reporting.

My role sits at the intersection of Senior SDET, Test Infrastructure, DevOps and Quality Engineering. I build scalable systems that reduce manual regression, identify integration failures earlier, improve release confidence, and give Engineering and Product teams clear information they can act on.

**Playwright + TypeScript Automation | CI/CD Integration | E2E | infrastructure Orchestration | SaaS | REST | GraphQL | Swagger / OpenAPI | Postman | k6 & Grafana Load and stress | GenAI | Agentic AI | Jenkins | GitHub Actions | Bitbucket Pipelines | Azure DevOps | Docker | Render CD | GitHub CLI**

## What I deliver
- Scalable automation platforms built from scratch and designed for team-wide adoption.
- Reliable release coverage across UI, API, Frontend, backend, data, and cross-system workflows.
- Dockerized, isolated, and parallel test execution integrated into CI/CD quality gates.
- Test-data provisioning and cleanup designed for repeatable and parallel-safe execution.
- Actionable failure diagnostics and reporting that help Engineering and Product make faster release decisions.
- Performance, load and stress testing with k6, JMeter, and Grafana-oriented reporting
- AI-assisted (agentic AI) workflows that improve test generation, analysis, regression planning, documentation, and orchestration.
- Multi-tenant Playwright automation for SaaS, commerce, and operational platforms
- Business-flow coverage across UI/UX, API, backend, data, permissions, tenant switching, packages, and licensing
- REST, GraphQL, Swagger / OpenAPI, Postman, curl, Auth / JWT, and role-based validation scenarios
